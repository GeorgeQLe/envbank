# EnvBank v0.1.1 provenance release ship manifest

## User goal

Prepare v0.1.1 as a corrective, anonymously verifiable alpha release while
leaving v0.1.0 and its published assets untouched.

## Changed files and purpose

- `.github/workflows/release.yml`: limit publication to an annotated v0.1.1
  tag on protected `main`; build the four native archives, checksums, SPDX JSON
  SBOM, and AMD64/ARM64 image; preserve artifact and image Sigstore bundles;
  update the `0.1` channel; and refuse to overwrite an existing release.
- `.github/release-notes-v0.1.1.md`: describe the corrective release, exact
  asset surface, verification route, supported platforms, and alpha limits.
- `scripts/verify-release-anonymous.sh`: isolate GitHub, Git, and Docker
  credentials; validate anonymous clone/redirect/download access; verify
  archives, checksums, SBOM, bundles, source identity, image platforms and
  digest; and test `/healthz` with scoped cleanup.
- `README.md`, `CHANGELOG.md`, and `cmd/envbank/main_test.go`: advance release
  examples and link-time version expectations to v0.1.1 while explicitly
  retaining v0.1.0 as immutable and provenance-incomplete.
- `tasks/todo.md`, `tasks/history.md`, and this manifest: record preparation,
  the shipping boundary, and the still-required publication and evidence work.

## User-goal mapping

The release workflow creates exactly the eight planned assets and two public
provenance bundles, publishes the versioned and `0.1` image tags, gates on an
annotated tag whose peeled commit is on protected `main`, and fails if the
release already exists. The verifier covers every anonymous assertion and
preserves pre-existing images while cleaning only its own temporary state.

## Tests run

- Bash 3.2 parsing, ShellCheck, and negative traversal/backslash/symlink archive
  fixtures for `scripts/verify-release-anonymous.sh`.
- `go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12`.
- Go formatting, `go mod verify`, `go mod tidy -diff`, `go test ./...`,
  `go test -race ./...`, and `go vet ./...`.
- `node --test extension/test/*.test.js`, `make recovery-drill`, and
  `make build-cross`.
- Pinned Govulncheck and go-licenses scans, full-history and working-directory
  Gitleaks scans, the synthetic secret fixture, and `git diff --check`.

The license scanner warned that platform assembly/syscall files in
`golang.org/x/sys/unix` cannot be inspected for further dependencies. This is
an accepted tool limitation for non-Go sources; its package license passed the
allowlist and no application dependency changed.

## Skipped tests

The public v0.1.1 download, attestation, registry, and health assertions cannot
run until this workflow is merged and the annotated tag publishes the release.
They remain unchecked in `tasks/todo.md` and are the required evidence phase.

## Adversarial review

The exact shipping diff was reviewed for credential leakage, unsafe archive
extraction, unpinned Actions, bypassable tag or branch checks, mutable release
behavior, missing provenance subjects, unsupported host/platform handling,
destructive Docker cleanup, and claims that precede public verification. The
review added rejection of archive links and unsupported entry types, exact
commit-date validation for the host binary, collision checks and created-state
guards for Docker cleanup, and Bash 3.2-compatible asset comparisons.

## Residual risk

GitHub-hosted runner availability, public Sigstore/TUF services, GHCR referrer
support, and public API behavior can only be proven by the tagged workflow and
the subsequent clean anonymous verification. Publication stops if any required
workflow check or verification assertion fails.

## Rollback note

Before tagging, revert the preparation squash commit. After tagging, preserve
v0.1.1 and publish a new corrective version instead of rewriting any tag,
release asset, provenance bundle, or image version.
